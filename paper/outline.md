# 논문 구성 (2026-09-09 개정 — 전문 작성 완료, 약 120면)

인제대학교 규정 순서(CLAUDE.md): 표지 → 표제지 → 인준서 → 목차(+표·그림 목차) →
국문초록 → 영문초록 → Ⅰ 서론 → Ⅱ 연구목적 → Ⅲ 연구재료 및 방법 → Ⅳ 연구성적 →
Ⅴ 고찰 → Ⅵ 결론 → 참고문헌 → 부록.

- 본문 원고: `paper/thesis_text.py` (장별 리스트, 참고문헌 dict)
- 생성기: `paper/build_thesis.py` → `paper/thesis.docx` (docx 직접 편집 금지)
  - 인용은 `{cite:key}` → 등장 순서 어깨번호 `n)`; 참고문헌은 그 순서로 자동 배열
  - 표·그림은 `[Table. 영문 제목 — tables/x.csv]`, `[Fig. 영문 제목 — figures/x.png]`
    자리표시자 → 등장 순서 번호(본문 1…, 부록 A1…); 본문 참조는 `{Table:x}`/`{Fig:x}`
  - 부록 원문 삽입: `[Verbatim — 저장소 상대경로]` (고정폭)
  - 목차 면번호: 1차 생성 → LibreOffice PDF → pdftotext로 면을 찾아 2차 생성
    (본문은 PAGEREF 필드, 전문부 로마 숫자는 고정 문자열)
- 부록 표 생성: `paper/make_appendix_tables.py` (appA~appD csv)

제목(제안, 지도교수 확정 전): 「사족보행 로봇의 험지 보행을 위한 강화학습 알고리즘
비교 및 대형 언어 모델 기반 보상 코칭에 관한 연구」

## 범위 (원 계획 대비)
| 축 | 원 계획 | 실제 |
|---|---|---|
| 알고리즘 | 6 | 핵심 행렬 4 (PPO, TRPO, SAC, TD3) × 3 지형 × 시드 0~2; DDPG 평지 시드 0 (탐험 2변형, 실패 기전 분해); A3C 미실행(GPU 벡터화와 구조 비호환, `a3c.py` NotImplementedError) |
| 로봇 | 3 | A1 본실험 + ANYmal C 이식(표 5) |
| 지형 | 12 × 3 난이도 | 평지·계단·요철 × 난이도 스케일링(표 4) |
| 시드 | 10 | 3 (0, 1, 2) |
| LLM 통합 | 하이브리드 보상 + 인간 선호 | **학습 중 보상 코치**(LLM / random / hillclimb / none) — 제2부 |
| 시뮬레이터 교차 검증 | PyBullet/Gazebo | 후속 과제 |
| 하드웨어 | A1 실기 | 후속 과제 |

제1부 평가 규약의 결함(에피소드 20회, 경쟁 편향, 목표 도달 종료 없음, 가장자리 낙상)은
Ⅲ.3.F(예비 실험)·Ⅴ.1.B에 명시하고, 제2부는 수정 규약(고정 256 env)으로 측정.

## 장별 내용 (모두 작성됨)
- Ⅰ 서론 5절(의의 / 관련 지견 A~C / 유도 / 주제 / 용어), Ⅱ 연구목적 2절
- Ⅲ 1 설계 개요, 2 재료 A~E, 3 방법 A~J(과제·보상·알고리즘 원리·신경망·예산·예비
  실험·평가·실패 기전 분해·분석·재현성), 4 코치 A~J(그림 1 구조도 포함)
- Ⅳ 1 알고리즘 비교 A~G(표 1~5, 그림 2~7), 2 코치 A~E(표 6~13, 그림 8~12)
  — 현상만 기술
- Ⅴ 1 타당성·신뢰성 A~F(Holm 보정 시 p 0.057/0.074 명시), 2 해석 A~J,
  3 미해석·후속 A~B
- Ⅵ 결론(숫자 없음), 참고문헌 89편(인용 순), 부록 A~G
  (A·B 코치 프롬프트 원문, C 조정 파라미터, D 내부 개정 이력, E 하이퍼파라미터,
  F 제1부 전체 학습 이력, G 제2부 실행별 성적)
